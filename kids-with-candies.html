🍬 拥有最多糖果的孩子

LeetCode 1431 · Kids With the Greatest Number of Candies

题目：有 n 个有糖果的孩子。给你一个数组 candies，其中 candies[i] 代表第 i 个孩子拥有的糖果数目，和一个整数 extraCandies 表示你所有的额外糖果数量。

返回一个布尔数组 result，如果把所有 extraCandies 给第 i 个孩子后，他会拥有所有孩子中 最多 的糖果，那么 result[i] 为 true，否则为 false。注意，允许有多个孩子同时拥有最多的糖果数目。

💡 核心思路

① 找到当前最大值

遍历 candies 数组，找到所有孩子中糖果数的最大值 maxCandy。这是判断的基准线。

② 逐个孩子判断

对每个孩子，计算 candies[i] + extraCandies，如果结果 ≥ maxCandy，则为 true。

③ 收集结果

将每个孩子的判断结果收集到数组中返回。可以用 map() 一行搞定。

💻 JavaScript 代码

function kidsWithCandies(candies, extraCandies) {
// Step 1: find the current maximum
const maxCandy = Math.max(...candies);
// Step 2: check each kid
return candies.map(c => c + extraCandies >= maxCandy);
}

⏱ 复杂度分析

时间复杂度：O(n) — 遍历两次数组
空间复杂度：O(n) — 存储结果数组
