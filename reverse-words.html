📝 反转字符串中的单词

LeetCode 151 · Reverse Words in a String

📋 题目描述

给你一个字符串 s，请你反转字符串中 单词 的顺序。

单词 是由非空格字符组成的字符串，s 中使用至少一个空格将字符串中的单词分隔开。
返回的字符串中，单词间应当仅用 单个空格 分隔，且不包含任何 额外的空格。

约束：1 ≤ s.length ≤ 10⁴，s 包含英文大小写字母、数字和空格 ' '，至少存在一个单词。

示例 1：输入 s = "the sky is blue" → 输出 "blue is sky the"

示例 2：输入 s = "  hello world  " → 输出 "world hello"

示例 3：输入 s = "a good   example" → 输出 "example good a"

💡 核心思路 — 分割 + 反转 + 拼接

① 去除多余空格

使用 trim() 去除首尾空格，为后续分割做准备。

② 按空格分割

用 split(/\s+/) 正则分割，自动处理多个连续空格，得到单词数组。

③ 反转数组

调用 reverse() 将单词数组顺序反转，即可实现单词倒序。

④ 拼接结果

使用 join(' ') 用单个空格连接所有单词，返回最终结果。

🎮 交互控制

💻 JavaScript 代码

var reverseWords = function(s) {
// Step 1: trim leading/trailing spaces
s = s.trim();
// Step 2: split by one or more spaces
const words = s.split(/\s+/);
// Step 3: reverse the array
words.reverse();
// Step 4: join with single space
return words.join(' ');
};
时间复杂度：O(n) — 遍历字符串一次 空间复杂度：O(n) — 存储单词数组
