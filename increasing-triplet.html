📈 递增的三元子序列

LeetCode 334 · Increasing Triplet Subsequence

📋 题目描述

给你一个整数数组 nums，判断这个数组中是否存在长度为 3 的递增子序列。

即是否存在下标 i、j、k，满足 i < j < k 且 nums[i] < nums[j] < nums[k]。
如果存在，返回 true；否则返回 false。

进阶：你能实现时间复杂度为 O(n)、空间复杂度为 O(1) 的解决方案吗？

示例 1：nums = [1,2,3,4,5] → true   三元组 (1,2,3)

示例 2：nums = [5,4,3,2,1] → false   不存在递增三元组

示例 3：nums = [2,1,5,0,4,6] → true   三元组 (0,4,6)

💡 核心思路 — 贪心双哨兵

① 维护 first 最小值

变量 first 始终存储遍历过程中遇到的 最小值。当 nums[i] ≤ first 时更新它，让后续更容易找到递增序列。

② 维护 second 次小值

变量 second 存储 大于 first 的最小值。当 nums[i] ≤ second 时更新它。此时已找到长度为 2 的递增序列。

③ 发现第三个即成功

一旦遇到 nums[i] > second，说明找到了 first < second < nums[i]，三元递增子序列存在，返回 true！

🎮 交互控制

💻 JavaScript 代码

var increasingTriplet = function(nums) {
let first = Infinity; // the smallest so far
let second = Infinity; // second smallest (> first)
for (const num of nums) {
if (num <= first) {
first = num; // update smallest
} else if (num <= second) {
second = num; // update second smallest
} else {
return true; // found triplet!
}
}
return false;
};
时间复杂度：O(n) — 一次遍历 空间复杂度：O(1) — 只用两个变量
