🧬 字符串的最大公因子

LeetCode 1071 · Greatest Common Divisor of Strings

题目：对于字符串 s 和 t，只有在 s = t + t + ... + t（即 t 自身连接1次或多次）时，我们才认定 "t 能除尽 s"。 给你两个字符串 str1 和 str2，请你找出最长字符串 x，要求 x 能除尽 str1 且 x 能除尽 str2。

💡 核心思路

① 判断是否存在公因子

如果 str1 + str2 ≠ str2 + str1，则不存在公因子，直接返回空串。这是因为两个字符串必须由同一个基础串重复构成。

② 利用 GCD 求公因子长度

如果存在公因子，其长度一定是 gcd(len1, len2)。利用辗转相除法求两个长度的最大公约数。

③ 截取并返回结果

最大公因子就是 str1.substring(0, gcdLen)，即 str1 的前 gcdLen 个字符。

💻 JavaScript 代码

function gcdOfStrings(str1, str2) {
// Step 1: check if GCD string exists
if (str1 + str2 !== str2 + str1) return "";
// Step 2: GCD of two lengths using Euclidean algorithm
const gcd = (a, b) => b === 0 ? a : gcd(b, a % b);
// Step 3: return the GCD string
return str1.substring(0, gcd(str1.length, str2.length));
}
