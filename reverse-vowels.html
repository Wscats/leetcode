🔤 反转字符串中的元音字母

LeetCode 345 · Reverse Vowels of a String

📋 题目描述

给你一个字符串 s，仅反转字符串中的所有 元音字母，并返回结果字符串。

元音字母包括：a e i o u（大小写均算）。

示例 1：输入 s = "IceCreAm" → 输出 "AcesreIm"

示例 2：输入 s = "leetcode" → 输出 "leotcede"

💡 核心思路 — 双指针对撞

① 识别元音

将 aeiouAEIOU 存入集合 Set，用于 O(1) 判断某字符是否为元音字母。

② 双指针对撞

左指针 left 从头、右指针 right 从尾出发，向中间逼近，直到相遇。

③ 跳过辅音

左指针遇到辅音就右移，右指针遇到辅音就左移，直到两端都指向元音。

④ 交换元音

当左右指针都指向元音时，交换两者位置的字符，然后同时向中间收缩。

🎮 交互控制

💻 JavaScript 代码

function reverseVowels(s) {
const vowels = new Set('aeiouAEIOU');
const arr = s.split('');
let left = 0, right = arr.length - 1;
while (left < right) {
while (left < right && !vowels.has(arr[left]))
left++; // skip consonant on left
while (left < right && !vowels.has(arr[right]))
right--; // skip consonant on right
[arr[left], arr[right]] = [arr[right], arr[left]];
left++;
right--;
}
return arr.join('');
}
时间复杂度：O(n) — 双指针各走一遍 空间复杂度：O(n) — 字符数组
