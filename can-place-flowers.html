🌸 种花问题

LeetCode 605 · Can Place Flowers

📋 题目描述

假设有一个很长的花坛，一部分地块种植了花，另一部分没有。花 不能种植在相邻的地块上，它们会争夺水源。

给你一个整数数组 flowerbed，由 0（空地）和 1（有花）组成，以及一个整数 n。
能否在不打破种植规则的情况下种入 n 朵花？能则返回 true，不能则返回 false。

提示：1 ≤ flowerbed.length ≤ 2×10⁴，flowerbed[i] 为 0 或 1，数组中不存在相邻的两朵花。

💡 核心思路 — 贪心算法

① 贪心策略

从左到右扫描，遇到能种花的位置就 立即种下。尽早种花不会让后续结果更差。

② 三条件判断

位置 i 能种花需同时满足：
• bed[i] == 0
• 左邻居为 0 或不存在
• 右邻居为 0 或不存在

③ 种下并标记

种花后将 bed[i] 设为 1，计数器 count++。这样后续检查自动跳过相邻位。

④ 提前退出

当 count ≥ n 时可立即返回 true，无需继续遍历，提升效率。

🎮 交互控制

💻 JavaScript 代码

function canPlaceFlowers(flowerbed, n) {
let count = 0;
for (let i = 0; i < flowerbed.length; i++) {
if (flowerbed[i] === 0) {
const leftOk = i === 0 || flowerbed[i - 1] === 0;
const rightOk = i === flowerbed.length - 1 || flowerbed[i + 1] === 0;
if (leftOk && rightOk) {
flowerbed[i] = 1; // plant here
count++;
if (count >= n) return true;
}
}
}
return count >= n;
}
时间复杂度：O(n) — 单次遍历花坛 空间复杂度：O(1) — 原地修改
