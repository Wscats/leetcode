🧮 除自身以外数组的乘积

LeetCode 238 · Product of Array Except Self

📋 题目描述

给你一个整数数组 nums，返回数组 answer，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。

题目保证：任意前缀或后缀的乘积都在 32 位整数范围内。
要求：请 不要使用除法，且在 O(n) 时间复杂度内完成。

进阶：你可以在 O(1) 的额外空间复杂度内完成这个题目吗？（出于学习目的，输出数组不被视为额外空间）

示例 1：nums = [1,2,3,4] → answer = [24,12,8,6]

示例 2：nums = [-1,1,0,-3,3] → answer = [0,0,9,0,0]

💡 核心思路 — 左右前缀积（两次遍历）

① 左侧前缀积

从左到右遍历，answer[i] 累乘 nums[0..i-1]，即当前元素 左边所有数的乘积。

② 右侧后缀积

从右到左遍历，用变量 R 累乘 nums[i+1..n-1]，再与 answer[i] 相乘，叠加 右边所有数的乘积。

③ 无除法 O(1) 空间

答案数组 answer 既存左前缀积又被更新为最终结果，只需一个额外变量 R，空间 O(1)。

🎮 交互控制

💻 JavaScript 代码

var productExceptSelf = function(nums) {
const n = nums.length;
const answer = new Array(n).fill(1);
// Pass 1: left prefix product
let leftProduct = 1;
for (let i = 1; i < n; i++) {
leftProduct *= nums[i - 1];
answer[i] = leftProduct;
}
// Pass 2: right suffix product
let rightProduct = 1;
for (let i = n - 2; i >= 0; i--) {
rightProduct *= nums[i + 1];
answer[i] *= rightProduct;
}
return answer;
};
时间复杂度：O(n) — 两次线性遍历 空间复杂度：O(1) — 除输出数组外只用了常数空间
