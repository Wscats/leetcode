🗜️ 压缩字符串

LeetCode 443 · String Compression · 双指针原地压缩

📋 题目描述

给你一个字符数组 chars，请使用下述算法 原地 压缩：

从一个空字符串 s 开始。对于 chars 中的每组 连续重复字符：
• 如果这一组的长度为 1，则将字符追加到 s 中。
• 否则，需要向 s 中追加字符，后跟这一组的 长度（数字的每一位作为单独字符）。

压缩后的字符串 s 不应该直接返回，而是存储在输入的字符数组 chars 中。
注意 chars 的长度被更新为压缩后的新长度。请返回该数组的 新长度。

⚠️ 必须原地修改，只允许 O(1) 额外空间。

示例 1：chars = ["a","a","b","b","c","c","c"]

→ 返回 6，chars 前6位 = ["a","2","b","2","c","3"]

示例 2：chars = ["a"]

→ 返回 1，chars = ["a"]（单个字符不写数字）

示例 3：chars = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]

→ 返回 4，chars 前4位 = ["a","b","1","2"]（12 拆成 "1" 和 "2"）

💡 核心思路 — 读写双指针 + 原地压缩

① read 读指针

read 指针负责 向前扫描，统计当前字符连续出现的次数，直到遇到不同字符或数组末尾。

② write 写指针

write 指针负责 原地写入 压缩结果。先写字符本身，若 count > 1 再写入计数数字的每一位。

③ 统计连续计数

内层循环从当前 read 开始，不断前进直到 chars[read] ≠ 当前字符，差值即为 count。

④ 写入规则

写入字符 → 若 count > 1，将数字转为字符串，逐位写入（处理 ≥ 10 的情况如 "12" → '1','2'）。

🎮 交互控制

💻 JavaScript 代码

var compress = function(chars) {
let write = 0; // write pointer
let read = 0; // read pointer
while (read < chars.length) {
const ch = chars[read]; // current char
let count = 0; // repetition count
while (read < chars.length && chars[read] === ch) {
read++; // advance read
count++; // increment count
}
chars[write++] = ch; // write the char
if (count > 1) { // write digits if > 1
for (const d of String(count)) {
chars[write++] = d; // write each digit
}
}
}
return write; // new length
};
时间复杂度：O(n) — 每个元素被读一次 空间复杂度：O(1) — 原地修改
